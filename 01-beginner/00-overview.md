# 초급(예비/신입 DBA) 단계 개요

이 문서는 DBA(Database Administrator, 데이터베이스 관리자)가 되기 위한 학습 여정의 **첫 번째 단계**를 안내합니다. DBA는 데이터베이스가 안정적으로 동작하도록 설치·운영·백업·모니터링을 책임지고, 개발자와 사용자가 데이터를 안전하고 빠르게 다룰 수 있게 돕는 사람입니다.

초급 단계의 목표는 한 문장으로 요약하면 이렇습니다: **"관계형 데이터베이스가 무엇인지 이해하고, 기본적인 SQL과 관리 명령을 스스로 실행할 수 있다."** 아직 성능 튜닝이나 대규모 장애 대응은 다루지 않습니다. 대신 앞으로 모든 심화 학습의 토대가 될 개념과 손에 익어야 할 기본기를 다집니다.

이 학습서는 특정 제품(벤더)에 얽매이지 않고 관계형 DB의 **공통 이론**을 먼저 설명한 뒤, 실무에서 가장 많이 쓰이는 세 가지 DBMS(**PostgreSQL / MySQL / Oracle**)의 명령어를 나란히 비교하는 방식으로 구성됩니다. 하나를 배우면 나머지도 쉽게 익힐 수 있도록 하기 위함입니다.

---

## 선수 지식 (거의 없어도 됩니다)

이 단계는 데이터베이스를 처음 접하는 사람을 대상으로 합니다. 다음 정도만 준비되어 있으면 충분합니다.

- **컴퓨터 기본 조작**: 파일과 폴더 개념, 프로그램 설치·실행이 가능한 수준
- **터미널(명령줄) 사용 경험**: `cd`, `ls`(또는 `dir`) 같은 기본 명령을 실행해 본 적이 있으면 좋습니다. 없어도 03장에서 함께 익힙니다.
- **간단한 영어 읽기**: 명령어와 오류 메시지는 대부분 영어로 되어 있습니다. 사전을 찾아가며 읽는 수준이면 됩니다.

프로그래밍 언어(Java, Python 등)를 몰라도 괜찮습니다. SQL은 이 단계에서 처음부터 배웁니다.

---

## 이 단계를 마치면 갖추게 되는 역량

초급 단계를 끝내면 다음을 할 수 있게 됩니다.

- **관계형 모델을 설명할 수 있다**: 테이블·행·열·관계가 무엇인지, 왜 데이터를 표 형태로 나누어 저장하는지 이해합니다.
- **정규화와 제약조건을 이해한다**: 데이터 중복을 줄이는 정규화(1NF~3NF)와 기본키·외래키·NOT NULL·UNIQUE 같은 제약조건의 역할을 압니다.
- **기본 SQL을 작성한다**: 테이블을 만들고(CREATE), 데이터를 넣고(INSERT), 조회·수정·삭제(SELECT/UPDATE/DELETE)하는 SQL을 스스로 작성합니다.
- **DBMS를 설치하고 접속한다**: PostgreSQL/MySQL/Oracle을 설치하고 서비스를 시작·중지하며, 클라이언트 도구(psql/mysql/sqlplus)로 접속합니다.
- **계정과 권한을 관리한다**: 사용자 계정을 만들고 삭제하며, 필요한 만큼만 권한을 부여(GRANT)하고 회수(REVOKE)합니다.
- **기본 백업을 수행한다**: 논리 백업 도구(pg_dump/mysqldump/expdp)로 데이터를 백업하고 복원하는 흐름을 이해합니다.
- **기본 상태를 점검한다**: 로그 파일을 확인하고, 현재 접속 세션과 디스크 사용량을 조회해 "지금 DB가 정상인가"를 판단합니다.

한마디로, **혼자서 작은 데이터베이스를 설치하고 운영해 볼 수 있는 수준**에 도달합니다.

## 다음 단계(중급)로 넘어가는 기준 체크리스트

아래 항목을 **모두** 스스로 할 수 있다고 느껴지면 중급 단계로 넘어갈 준비가 된 것입니다. 남에게 설명할 수 있을 정도가 되어야 진짜 이해한 것입니다.

- [ ] 테이블, 행, 열, 관계가 무엇인지 예를 들어 설명할 수 있다.
- [ ] ACID(원자성·일관성·격리성·지속성)의 각 글자가 무슨 뜻인지 말할 수 있다.
- [ ] 어떤 테이블을 보고 1NF/2NF/3NF를 만족하는지 판단할 수 있다.
- [ ] 기본키와 외래키의 차이, 그리고 외래키가 왜 필요한지 설명할 수 있다.
- [ ] CREATE / ALTER / DROP로 테이블을 다룰 수 있다.
- [ ] SELECT에 WHERE, ORDER BY, 간단한 JOIN을 붙여 원하는 데이터를 조회할 수 있다.
- [ ] INSERT / UPDATE / DELETE로 데이터를 변경하고, COMMIT / ROLLBACK으로 트랜잭션을 제어할 수 있다.
- [ ] PostgreSQL, MySQL, Oracle 중 하나 이상을 직접 설치하고 클라이언트로 접속할 수 있다.
- [ ] 새 사용자 계정을 만들고 특정 테이블에 대한 권한만 부여할 수 있다.
- [ ] pg_dump/mysqldump/expdp 중 하나로 백업 파일을 만들고 복원할 수 있다.
- [ ] 현재 접속 중인 세션과 디스크 사용량을 조회해 DB 상태를 점검할 수 있다.
- [ ] 오류가 났을 때 로그 파일을 찾아 원인의 실마리를 확인할 수 있다.

체크되지 않은 항목이 있다면 해당 장을 다시 복습한 뒤 실습을 반복하세요. 초급 단계에서 다진 기본기는 중급·고급 단계 내내 계속 쓰입니다.
